# Roadmap

What OverBench has and what comes next, release by release. Releases have no fixed dates: one goes out when enough has landed, so the order here is firmer than the timing. Each item links to its issue, where you can follow it or tell us what you need; the [milestones](https://github.com/overbench/overbench/milestones) hold the full lists, fixes included. [简体中文](./ROADMAP.zh-CN.md)

## Available now

In v0.0.2:

- Claude Code, Codex CLI and opencode side by side, over the Agent Client Protocol
- Session history, parallel sessions, sub-sessions and forks from any reply
- Permission cards answered with one key, and notifications when a session needs you
- Git status and pull requests, a files pane and a terminal for each project
- Token usage across agents, with plan limits
- Preview builds for macOS, Windows and Linux, with automatic updates on Windows and Linux
